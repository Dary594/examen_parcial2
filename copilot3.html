Funciones de Copilot

Estructura

Genera borradores, currículum y reescribe contenido.

Codificación

Analiza y ofrece sugerencias de código relevante en tiempo real.

Búsqueda

Resuelve preguntas y encuentra información en documentos, presentaciones, correo electrónico, calendario, notas y contactos.

Automatización

Automatiza tareas repetitivas.

Análisis de datos

Analiza y resume datos.

Visualización de datos

Visualiza información en gráficos y tablas dinámicas.

Resaltado de datos

Resalta datos interesantes.

Creación de presentaciones

Genera esquemas, diseña diapositivas y organiza el contenido.

Dónde está Copilot

Copilot está disponible en aplicaciones como Microsoft 365, Teams, Outlook y Edge.

Cómo funciona Copilot

Copilot se basa en LLM (Large Language Mode), un modelo de lenguaje entrenado con grandes cantidades de código.

Limitaciones de Copilot

Como todas las inteligencias artificiales, Copilot puede tener alucinaciones, es decir, puede dar información falsa.
